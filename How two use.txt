## 🔑 Access Levels

| Level | Description |
|-------|-------------|
| **Public** | No authentication required |
| **User** | Requires valid user token |
| **Admin** | Requires valid admin token |
| **User / Admin** | Either role can access |

---

## 📝 Notes

1. **Authentication**: Protected routes require a valid JWT token (typically via `Authorization: Bearer <token>` header).
2. **File Uploads**: Endpoints marked with `multipart` accept `multipart/form-data` with the specified field names.
3. **Validation**: All routes include request validators (express-validator) that run before the controller.
4. **Nested Routes**: Subcategories are accessible both as nested routes under categories and as standalone routes.
5. **Coupon & Favorite routes**: Apply `protect_route` and `allowed_to` middleware globally at the router level.
